# Predicción del precio de la vivienda en España

## Trabajo Fin de Máster en Ciencia de Datos

### Objetivo

Desarrollar modelos de Machine Learning para predecir el precio de viviendas en España utilizando datos reales del mercado inmobiliario.

### Dataset

- Más de 100.000 anuncios inmobiliarios.
- Variables estructurales de la vivienda.
- Variables geográficas.
- Variables socioeconómicas.

### Tecnologías

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- XGBoost
- SHAP
- Visual Studio Code
